Conectar a leitura do Analytics

A medição do site já existe. Para este painel consultar os relatórios, é necessário configurar o acesso da API no servidor.

  1. Habilite a Google Analytics Data API no projeto Google Cloud.
  2. Cadastre uma conta de serviço como Leitor na propriedade 534532275.
  3. Configure no Supabase os Secrets GOOGLE_SERVICE_ACCOUNT_JSON e GA4_PROPERTY_ID. A credencial fica apenas no servidor.

Depois, clique em Atualizar dados.

Como ler estes dados

Cada atualização consulta os relatórios disponíveis no Google naquele momento. O processamento do GA4 pode ter atraso e o dia atual pode estar incompleto. O período usa o fuso configurado na propriedade. Usuários ativos não devem ser somados entre dias, páginas ou países. Filtros de país e canal usam os nomes retornados pelo Google; o país deve corresponder exatamente (ex.: Brazil). O filtro de página se aplica a todos os relatórios.
